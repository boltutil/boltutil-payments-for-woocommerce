# Release copy — plugin v0.6.2

## Repository description

Accept USDT and USDC in WooCommerce with BoltUtil hosted checkout. Direct-to-wallet payments, signed webhooks, Classic Checkout, Checkout Blocks and HPOS. Requires a BoltUtil account and a USD store.

Repository website: https://boltutil.com/woocommerce

Demo website: https://shop-test.boltutil.com/

## English announcement

Accept USDT and USDC in WooCommerce with BoltUtil. Customers choose a stablecoin and one of the available networks, then continue to Hosted Checkout. On supported devices, connect a wallet to fill in the address and exact amount, review and confirm; manual transfer is also available. Confirmed payments are checked before the plugin updates the order.

Plugin v0.6.2 supports six networks and eleven token/network combinations, including native USDC and Bridged USDT on Base. Its GitHub installation ZIP includes English and eleven translations; WordPress.org uses published language packs. Daily allowances and subscription benefits follow the current BoltUtil plans.

Try the public demo: https://shop-test.boltutil.com/ . Browsing is free; small digital purchases use real funds. Download: https://github.com/boltutil/boltutil-payments-for-woocommerce/releases/tag/v0.6.2 . The plugin is published in the WordPress.org Plugin Directory: https://wordpress.org/plugins/boltutil-payments-for-woocommerce/ .

## Publishing rules

- The plugin, hosted service and public documentation have separate version histories.
- Quick-payment options depend on network, token, device and wallet support. Do not promise every wallet on every chain.
- Use the exact Hosted Checkout amount; fees are separate. No fixed Base confirmation time is promised.
- Product screenshots show real interface states, not proof that a blockchain payment completed.
- Source docs are available in eleven translated introductions linked from README. Runtime translations follow WordPress locales; merchant-written labels do not translate automatically.
- The plugin is published on WordPress.org. Do not claim automatic refunds, guaranteed search ranking, universal free payments or benefits outside the published subscription terms.
- Base uses L2 confirmation by default and confirms an order after the configured requirements are met. Strict mode waits for L1 finality. Timing depends on network and service conditions; no fixed confirmation time is guaranteed.
- The GitHub installation ZIP includes English source text and eleven bundled translations. The WordPress.org edition uses WordPress language packs; available translations depend on published packs and the selected WordPress locale. Merchant-written checkout labels are not translated automatically.
