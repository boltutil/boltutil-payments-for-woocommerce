# WordPress.org listing artwork

Screenshot capture/review date: **2026-11-16**. These files are maintained for the GitHub documentation and WordPress.org listing. Updating this GitHub directory does not publish the files to WordPress.org; that requires a separate SVN assets update. [Public plugin listing](https://wordpress.org/plugins/boltutil-payments-for-woocommerce/).

Banner sizes: 1544 × 500 and 772 × 250. Rounded transparent corners retain the approved BoltUtil / USDT / USDC artwork, without a version label. Image Gen edited the outer outline of the selected banner; PNG exports preserve alpha. All screenshots are 1280 × 1060. The local renderer and preview captures use a presentation frame; the public storefront image is a direct browser capture. Original interface proportions are preserved.

1. USDT selection: actual v0.6.2 gateway renderer, six sample merchant-enabled routes, current network ordering and Base identifier.
2. USDC selection: the same renderer, five sample routes; TRON USDC is not offered.
3. Actual v0.6.2 setup-guide renderer in a local sample store; no credentials are supplied.
4. Read-only capture of the public BoltUtil Studio homepage. Browsing and its interaction preview are free; submitted purchases use real funds.
5. Current demo-store wallet-payment component, Ethereum / USDT and nine wallet options; illustrative data.
6. The same component in manual-transfer mode, with a demonstration address and QR code.

Screenshots 1–3 run the released PHP rendering methods and unchanged plugin CSS/JavaScript with local WordPress helper stubs and synthetic capabilities. They are not captures of a live Checkout Blocks transaction; the surrounding WooCommerce layout depends on the theme. Screenshots 5–6 run the current demonstration component with its original layout and proportional scaling. They do not demonstrate a real wallet connection or completed payment. Their address and QR code cannot be used to pay. No secrets, personal customer details or live order tokens are included. Brand names identify integrations and do not imply endorsement. BoltUtil releases its directory artwork under GPLv2 or later.

These files belong in the top-level SVN assets directory, outside trunk and tags. Keep the required dimensions and matching readme captions. [WordPress.org asset rules](https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/). Preserve these selected banners when regenerating older programmatic artwork.
